# Seeds

This repository contains "seeds" which are used by [Germinate](Germinate) to generate [metapackages](https://github.com/live-performer/metapackages). See [this page](http://manpages.ubuntu.com/manpages/eoan/en/man1/germinate.1.html) for more information on syntax

# Platform

Seeds from platform directory are from Ubuntu's official repository https://git.launchpad.net/~ubuntu-core-dev/ubuntu-seeds/+git/platform
